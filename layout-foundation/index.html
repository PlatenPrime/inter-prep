Паттерн: sidebar-layout

Две колонки: sidebar + main

На экранах < 1024px колонки становятся вертикальным стеком. Цветные фоны помогают увидеть границы зон.

sidebar

Боковая панель

Фиксированная ширина на desktop (16rem). Меню, фильтры, навигация по разделам.

main

Основной контент

Занимает всё оставшееся пространство (flex: 1). Сюда кладёшь статьи, формы, таблицы.

Правило: сначала разметь скелет (header → main → footer), потом внутри main — container, потом секции.

Паттерн: grid-3

Сетка из трёх колонок

1 колонка на mobile → 2 на tablet (768px) → 3 на desktop (1024px).

Карточка 1

Grid автоматически распределяет элементы по колонкам одинаковой ширины.

Карточка 2

Используй grid для каталогов, галерей, дашбордов.

Карточка 3

Gap между ячейками задаётся одним свойством на весь grid.

Паттерн: cluster

Кнопки и теги в ряд

Cluster — flex с wrap. Элементы переносятся на новую строку, если не помещаются.
