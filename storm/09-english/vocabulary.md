# English — 30 терминов для техдокументации

> Вакансия: англійська на рівні **читання документації**.  
> Прочитай вслух, потом закрой правую колонку и вспомни перевод.

## Core JavaScript

| Term | Значение / контекст |
|------|---------------------|
| **primitive** | Примитивный тип (string, number, …) |
| **reference** | Ссылка на объект в памяти |
| **hoisting** | «Поднятие» объявлений |
| **closure** | Замыкание |
| **callback** | Функция, переданная как аргумент |
| **promise** | Объект асинхронного результата |
| **resolve / reject** | Успех / ошибка Promise |
| **async / await** | Синтаксис над Promise |
| **immutable** | Неизменяемый (не мутировать) |
| **iteration** | Перебор (loop, forEach) |

## DOM & Web

| Term | Значение |
|------|----------|
| **DOM** | Document Object Model — дерево страницы |
| **element** | HTML-элемент (`<div>`, `<button>`) |
| **attribute** | Атрибут (`class`, `href`) |
| **event listener** | Обработчик события |
| **delegation** | Делегирование событий на родителя |
| **semantic** | Семантический (несущий смысл) |
| **accessibility (a11y)** | Доступность |
| **viewport** | Видимая область экрана |

## CSS

| Term | Значение |
|------|----------|
| **cascade** | Каскад — порядок применения стилей |
| **specificity** | Специфичность селектора |
| **flexbox** | Flex-раскладка |
| **media query** | Условные стили по ширине/типу |
| **breakpoint** | Точка перелома адаптива |

## Git

| Term | Значение |
|------|----------|
| **repository (repo)** | Репозиторий |
| **commit** | Снимок изменений |
| **branch** | Ветка |
| **merge** | Слияние веток |
| **pull request (PR)** | Запрос на слияние + review |

## React / Vue (docs)

| Term | Значение |
|------|----------|
| **component** | Компонент UI |
| **props** | Входные свойства (React/Vue) |
| **state** | Внутреннее состояние |
| **hook** | React hook (`useState`, …) |
| **directive** | Директива Vue (`v-if`, …) |
| **reactive** | Реактивный (авто-обновление UI) |

## Фразы для собеседования EN

| Ситуация | Фраза |
|----------|-------|
| Не расслышал | *"Could you repeat the question, please?"* |
| Нужно время подумать | *"Let me think for a moment."* |
| Не знаю, но учусь | *"I haven't used that in production yet, but I'd start with the official docs."* |
| Уточнение задачи | *"Should I optimize for readability or performance?"* |
| Конец | *"Do you have any questions about my background?"* |
