# Soft skills — behavioral (STAR)

> **Формат STAR:** Situation → Task → Action → Result (2–3 мин на историю).  
> **Мова:** на собесі можуть питати українською — підготуй відповіді UA, ключові терміни EN.

Критерії з вакансії: **обучаемость**, **командная работа**, **инициативность**, **проблемное мышление**.

---

## Как отвечать на «не знаю»

**Answer (EN):**  
*"I haven't worked with that yet, but here's how I'd approach learning it: read official docs, build a small repro, ask a teammate after I've tried — and document what I learned."*

Це **плюс**, не мінус — показує problem-solving і здатність до навчання.

---

## История 1 — Здатність до навчання (Learning agility)

### Вопрос (UA/RU)
*Розкажіть про випадок, коли вам довелося швидко освоїти новий інструмент або технологію.*

### Шаблон STAR

| | Содержание |
|---|------------|
| **S** | Навчальний проєкт / курс / pet project — потрібно було зробити інтерактивний UI за тиждень |
| **T** | Освоїти основи JavaScript + основи React (або Vue) для робочого прототипу |
| **A** | Офіційна документація → 1 маленький туторіал → 1 фіча в коді (форма, список) → code review у чаті / у друга |
| **R** | Прототип працює; зафіксував нотатки в README; наступну фічу зробив швидше |

### Ключевая фраза EN
*"I break learning into docs, a minimal example, and one real feature in code — then iterate."*

**Заполни своими деталями:** назва проєкту, конкретна фіча, скільки часу.

## История 2 — Командна робота (Teamwork)

### Вопрос (UA/RU)
*Як ви працюєте в команді? Був конфлікт думок або code review з жорсткими коментарями?*

### Шаблон STAR

| | Содержание |
|---|------------|
| **S** | Груповий проєкт або open source — різні думки щодо структури компонентів |
| **T** | Змерджити PR без образ; знайти рішення, зручне для всіх |
| **A** | Вислухав аргументи; запропонував маленький POC; погодились на спільний стиль (lint, naming); прийняв коментарі review без «ego» |
| **R** | PR змерджено; наступні PRи швидші завдяки узгодженим правилам |

### Ключевая фраза EN
*"I treat code review as collaboration — I ask why, not defend my ego, and document team decisions."*

## История 3 — Ініціативність (Initiative)

### Вопрос (UA/RU)
*Коли ви проявили ініціативу без прямого доручення?*

### Шаблон STAR

| | Содержание |
|---|------------|
| **S** | У проєкті повторювалися одні й ті самі баги в формах (валідація, accessibility) |
| **T** | Ніхто не ставив задачу — але страждала якість |
| **A** | Додав перевірку label+input, виніс спільний компонент поля, описав у PR чому це важливо |
| **R** | Менше регресій; команда почала реюзати компонент |

### Альтернатива
Запропонував `.gitignore` / README з інструкцією запуску / невеликий рефакторинг імен змінних.

### Ключевая фраза EN
*"When I see repeated pain, I propose a small fix with clear scope — not a rewrite."*

## История 4 — Проблемне мислення (Problem solving)

### Вопрос (UA/RU)
*Опишіть складну технічну проблему та як ви її вирішували.*

### Шаблон STAR

| | Содержание |
|---|------------|
| **S** | Код «не працює» — білий екран / тест падає / стилі зламані після merge |
| **T** | Знайти причину без паніки; відновити робочий стан |
| **A** | Відтворив локально → `console.log` / DevTools → прочитав stack trace → звузив (останній commit / conflict) → MDN або issue на GitHub → якщо застряг 30 хв — питання колезі з конкретним контекстом |
| **R** | Баг виправлено; додав тест або чеклист, щоб не повторилось |

### Ключевая фраза EN
*"I reproduce, isolate, read the error, check recent changes, then ask with a minimal repro — not just 'it doesn't work'."*

## Додаткові питання (короткі відповіді)

### Чому frontend? / Чому ця компанія?
- Подобається **видимий результат** роботи в браузері
- Хочу рости від **бази (HTML/CSS/JS)** до фреймворків у команді
- Готовий **вчитися** під менторство

### Слабкі сторони?
- Чесно: *"Глибина в [X] ще слабка — компенсую систематичною практикою й питаннями"*
- Не кажи: «перфекціоніст» без прикладу

### Де бачиш себе через рік?
- *"Confident junior/middle-: самостійні фічі, code review, можливо менторство новачків"*
