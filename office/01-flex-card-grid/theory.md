# 01 — Flex Card Grid

## Формулировка задачи

> «Сверстайте каталог товаров: карточки с картинкой, названием, ценой и кнопкой. На телефоне — одна колонка, на планшете — две, на десктопе — три. Без фреймворков.»

## Теория

**Flexbox** — одномерный лейаут: элементы выстраиваются в ряд или колонку. Контейнеру задают `display: flex`, дочерние элементы становятся flex-элементами.

Ключевые свойства контейнера:
- `flex-wrap: wrap` — перенос на новую строку при нехватке места
- `gap` — отступы между элементами без margin-хаков

Ключевые свойства элемента:
- `flex: 1 1 100%` — shorthand для `flex-grow`, `flex-shrink`, `flex-basis`
- `max-width` вместе с `flex-basis` фиксирует ширину колонки при wrap

**Mobile-first**: базовые стили для узкого экрана, `@media (min-width: …)` добавляют колонки.

**DocumentFragment** — лёгкий контейнер для пакетной вставки DOM без лишних reflow.

## Разбор решения

1. `.card-grid` — flex-контейнер с `flex-wrap` и `gap`.
2. `.card` — `flex-direction: column`, чтобы кнопка прижималась вниз через `flex: 1` на описании.
3. Breakpoints: `36rem` (576px) → 2 колонки, `56rem` (896px) → 3 колонки.
4. Формула ширины: `calc(50% - gap/2)` учитывает `gap` между карточками.
5. Делегирование клика на `#cardGrid` — один listener на все кнопки «В корзину».

## Типичные ошибки

- Забыть `flex-wrap` — карточки сжимаются вместо переноса.
- Использовать фиксированную ширину в px вместо адаптивных колонок.
- Не учитывать `gap` в `calc()` — ломается вторая строка.
- `width: 33%` без `box-sizing: border-box` — переполнение из-за padding.
