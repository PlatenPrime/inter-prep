# 04 — Sticky Table

## Формулировка задачи

> «Есть таблица сотрудников на 50+ строк. Контейнер ограничен по высоте и скроллится. Шапка таблицы должна оставаться на месте. Добавьте сортировку по клику на заголовок.»

## Теория

**position: sticky** — элемент ведёт себя как relative, пока не достигнет порога (`top`), затем «прилипает» как fixed внутри scroll-контейнера.

Условия работы sticky:
- У предка не должно быть `overflow: hidden` (кроме `visible`/`auto`/`scroll` на правильном контейнере)
- Задан `top` (или `bottom`)
- Достаточная высота scroll-области

**overflow: auto** на `.table-wrap` — создаёт scroll container.

**border-collapse: collapse** — классические таблицы; sticky на `th` работает в современных браузерах.

**Zebra stripes**: `tr:nth-child(even)` — чередование фона без лишней разметки.

## Разбор решения

1. `.table-wrap { max-height; overflow: auto }` — скролл только у таблицы.
2. `thead th { position: sticky; top: 0; z-index: 1; background }` — фон обязателен, иначе строки просвечивают.
3. JS генерирует tbody, сортировка через `Array.sort` + переключение `asc/desc`.
4. Визуальный индикатор сортировки через классы и `::after`.

## Типичные ошибки

- Sticky без `background` на th — контент «наезжает» под шапку.
- `overflow: hidden` на родителе ломает sticky.
- Забыть `scope="col"` на th — a11y.
- Сортировать исходный массив мутацией без копии — побочные эффекты.
