# Office — практика HTML + CSS + JS

10 автономных примеров типичных заданий на офисном этапе собеседования (~2 часа).
Каждая папка — готовая реализация + `theory.md` с теорией и разбором.

## Как использовать

1. Откройте `index.html` нужной задачи в браузере (двойной клик или Live Server).
2. Прочитайте `theory.md` — формулировка, концепции, типичные ошибки.
3. Закройте папку и попробуйте воспроизвести с нуля за 15–20 минут.

Никаких зависимостей от остального репозитория — только vanilla HTML/CSS/JS.
