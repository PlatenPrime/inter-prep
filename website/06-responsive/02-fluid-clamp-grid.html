Fluid clamp + grid

Заголовок и отступы плавно масштабируются через clamp(). Сетка карточек — auto-fit minmax без жёстких breakpoints.

Features

⚡

Fast

Карточки перестраиваются автоматически.

📐

Fluid

clamp() вместо фиксированных px.

🎯

Precise

minmax(min(100%, 16rem), 1fr) — без overflow.

📱

Responsive

1–4 колонки в зависимости от ширины.

--text-xl: clamp(1.5rem, 1.2rem + 1vw, 2rem);
--space-section: clamp(2rem, 5vw, 4rem);
grid-template-columns: repeat(auto-fit, minmax(min(100%, 16rem), 1fr));
