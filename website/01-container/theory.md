# 01 — Ограничивающий контейнер

## Проблема

На широком мониторе текст и карточки растягиваются на всю ширину — читать неудобно, выглядит «размазано». Нужен **контейнер**: блок с максимальной шириной, центрированный на странице, с отступами от краёв экрана.

## Мостик от SPA

В React часто используют `<Container maxWidth="1200px">` или Tailwind `max-w-7xl mx-auto px-4`. В чистом CSS — тот же паттерн, только класс `.container`:

```css
.container {
  width: 100%;
  max-width: 72rem;        /* ~1152px */
  margin-inline: auto;     /* центрирование */
  padding-inline: 1rem;    /* gutters — отступ от края экрана */
}
```

## Рецепт: базовый контейнер

| Свойство | Зачем |
|----------|-------|
| `width: 100%` | На узком экране контейнер занимает всю ширину |
| `max-width` | На широком — ограничивает контент |
| `margin-inline: auto` | Центрирует блок (левый и правый margin = auto) |
| `padding-inline` | **Gutters** — отступ от края viewport, чтобы текст не прилипал к краю |

### Почему padding-inline, а не фиксированная ширина?

Если задать `width: 1152px`, на экране 360px появится горизонтальный скролл. Паттерн `width:100% + max-width + padding` работает на любом экране.

## Рецепт: full-bleed секция

Иногда нужна секция **на всю ширину экрана** (цветной фон, картинка), но **текст внутри** — в контейнере:

```html
<section class="section--full-bleed">
  <div class="container">
    <h2>Заголовок</h2>
    <p>Текст ограничен контейнером</p>
  </div>
</section>
```

```css
.section--full-bleed {
  background: #1e293b;   /* фон на всю ширину */
  padding-block: 3rem;
}
/* .container внутри — как обычно */
```

**Правило:** фон/картинка — на внешней секции; контент — во внутреннем `.container`.

## Типовые ошибки

| Ошибка | Симптом | Решение |
|--------|---------|---------|
| `width: 1200px` без `max-width` | Горизонтальный скролл на мобилке | `width: 100%; max-width: 72rem` |
| Нет `padding-inline` | Текст прилипает к краю на 320px | Добавить `padding-inline: 1rem` |
| Контейнер на `<body>` | Full-bleed секции не работают | Контейнер — внутри каждой секции |
| `margin: 0 auto` вместо `margin-inline` | Работает, но менее явно | Предпочитать logical properties |
