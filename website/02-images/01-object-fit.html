01 — Object-fit

aspect-ratio + object-fit — контроль заполнения области

cover — обрезка краёв
contain — вся картинка видна
fill — сплющивание (избегай)
Рецепт: обёртка с aspect-ratio → img с width/height: 100% → object-fit: cover для карточек. Без aspect-ratio страница «прыгает» при загрузке изображения.
