# 07 — Пиксель-перфект

## Проблема

«Пиксель-перфект» — когда вёрстка визуально совпадает с макетом (Figma). Разработчики SPA часто не сталкиваются с этим: UI-kit сам задаёт отступы. На лендинге каждый блок верстают «с нуля» — и расхождения накапливаются.

## Мостик от SPA

В React-проекте с Tailwind/Shadcn отступы берут из design system (`p-4`, `gap-6`). На лендинге нужно **самому** задать шкалу и придерживаться её — иначе 17px тут, 19px там, и макет «плывёт».

## Рецепт: box-sizing и rem

```css
*, *::before, *::after {
  box-sizing: border-box;
}

html {
  font-size: 100%;  /* 1rem = 16px по умолчанию */
}
```

**rem** для отступов и типографики — масштабируется с настройками пользователя, консистентнее px.

## Рецепт: spacing scale (design tokens)

```css
:root {
  --space-1: 0.25rem;   /* 4px */
  --space-2: 0.5rem;    /* 8px */
  --space-3: 0.75rem;   /* 12px */
  --space-4: 1rem;      /* 16px */
  --space-6: 1.5rem;    /* 24px */
  --space-8: 2rem;      /* 32px */
  --space-12: 3rem;     /* 48px */
  --space-16: 4rem;     /* 64px */
}
```

**Правило:** используй только значения из шкалы. Если в макете 18px — округли до 16px (`--space-4`) или 20px (`--space-5` = 1.25rem).

## Рецепт: выравнивание по сетке

1. **Контейнер** — одинаковый `max-width` и `padding-inline` на всех секциях.
2. **Вертикальный ритм** — секции: `padding-block: var(--space-12)` или `--space-16`.
3. **Межэлементные отступы** — кратны `--space-2` или `--space-4`.

## Воркфлоу сверки с макетом

1. **DevTools** — Inspect элемент, смотри computed styles (padding, margin, font-size).
2. **Overlay** — в Figma экспорт PNG на 100% и наложи полупрозрачно (расширения типа PerfectPixel или встроенный overlay в DevTools).
3. **Измерения** — линейка в Figma vs computed в браузере.
4. **Шрифты** — проверь `line-height`, `letter-spacing`, `font-weight` — часто забывают.

### Что НЕ гоняться

- Субпиксельные различия (0.5px) на разных мониторах.
- Идеальное совпадение на всех zoom-уровнях.
- 100% совпадение с макетом на 4K, если макет 1440px — сверяй на целевом breakpoint.

## Типовые ошибки

| Ошибка | Симптом | Решение |
|--------|---------|---------|
| «Магические» px (17, 23, 37) | Неконсистентные отступы | Spacing scale |
| Разные gutters в секциях | Контент «прыгает» по горизонтали | Один `.container` |
| `content-box` | width не включает padding | `border-box` globally |
| Inline styles с px | Не масштабируется | CSS-переменные |
| Игнор line-height | Текст «выше/ниже» макета | Проверять в DevTools |
