Sticky header

Прокрути страницу вниз — хедер останется сверху благодаря position: sticky.

Секция 1

Контент для демонстрации скролла. Хедер не перекрывает начало страницы, потому что sticky не вырывает элемент из потока.

Секция 2

Обрати внимание на background и z-index у хедера — без них контент «просвечивает» при скролле.

Секция 3

Flex-раскладка: logo слева, nav по центру, CTA справа через justify-content: space-between.

Секция 4

Ещё контент для скролла.
